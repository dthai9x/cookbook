# Sales Data Analysis Script

This script analyzes sales data from a CSV file to calculate the total revenue and average order value.

## Usage

1.  Ensure you have the `pandas` library installed (`pip install pandas`).
2.  Place your sales data in a CSV file (e.g., `sales_data.csv`) with columns `order_id`, `product`, `quantity`, and `price`.
3.  Modify the `sample_csv_path` variable in the `sales_analysis.py` script to point to your CSV file.
4.  Run the script: `python sales_analysis.py`

The script will print the total revenue and average order value to the console.
